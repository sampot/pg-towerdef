# pg-towerdef

瀏覽器**迷你塔防**（可上線遊玩等級）：戰役 15 波／無盡、三難度、箭塔／炮塔／冰塔（最高 5 級），多敵種與首領波、加速、優先目標、連殺加成、傷害飄字與粒子。純前端；**mobile-first**。

也可當作 [Playgrounds（遊樂場）](https://play.samkuo.me/) 的 **SAM**（`index.html` 入口）。

## 操作

| 操作 | 說明 |
| --- | --- |
| 戰役／無盡 · 難度 | 開局前選擇 |
| 選塔 → 點空地 | 建造 |
| 點塔 | 檢視／升級／賣掉（有確認） |
| 下一波 · 自動波 | 放出敵人 |
| ×1～×3 | 加速 |
| 優先目標 | 最前／最肉／最近 |
